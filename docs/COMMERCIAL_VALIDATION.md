# HONET Commercial Validation

## Product

HONET turns observations, documents, diagrams, and research notes into structured observations and ranked questions for further investigation.

The product hypothesis is not that HONET automatically discovers truth. It is that a question-driven workflow can produce more useful, testable research directions than ordinary answer-first prompting.

## Validation sequence

1. Run the same input through a baseline LLM and HONET.
2. Generate 20 questions per system.
3. Blind-rate questions for usefulness, testability, factual grounding, and cross-domain value.
4. Track new graph nodes/edges created by each question.
5. Validate promising hypotheses against external evidence or experiments.
6. Interview prospective users before charging.
7. Offer a small paid pilot only after evidence of repeated value.
